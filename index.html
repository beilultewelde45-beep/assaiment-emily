How to Play

  • The A–K keys play the white piano keys.
  • W E T Y U play the black keys (sharp notes).
  • You can also click (or tap) the piano keys.
  • Choose a sound from the dropdown.
  • Select a song and follow the sequence.

About This Project

This project demonstrates JavaScript event listeners. The page listens for keydown and keyup events, finds the matching piano key with querySelector, and uses classList to light it up. The sounds are made with the Web Audio API.
